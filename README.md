# Thickness-dependent secondary-electron emission from suspended MoS2 membranes in the helium ion microscope

Data and analysis code for the manuscript

> C. Kim, D. Lister, P. Jackle, and K. L. Kavanagh,
> "Thickness-dependent secondary-electron emission from suspended MoS2 membranes
> in the helium ion microscope" (submitted to Applied Physics Letters).

Suspended MoS2 flakes on lacey carbon were imaged with a 30 keV He+ beam in a
transmission helium-ion-microscope (HIM) geometry, with local thickness
calibrated independently by STEM-EELS. This repository preserves the full
analysis path from the raw HIM images to the published fits: ROI intensity
extraction, Bayesian carbon-reference normalization, SE-escape model
comparison, statistical sensitivity campaigns, and the SRIM-based
transmitted-ion analyses.

## Repository layout

```
config/              Dataset and ROI-preparation configuration
data/
  raw_images/        Original HIM images (three transmission, two backside-blocked)
  roi_exports/       Raw per-ROI exports produced during image measurement
  roi_measurements/  Final per-ROI tables used by the Bayesian analysis
  roi_templates/     Projective-alignment templates for the blocked images
  reference_overlays/  Annotated images showing ROI locations
  reference_summaries/ Bayesian posterior summaries used by the model fits
  tape_series/       Copper-tape converter series raw images and ROI files
                     (control, small_tape, large_tape: three image sets each,
                     with ROI polygons, aligned polygons, and per-ROI tables;
                     backside_blocked and 45deg_converter hold the remaining
                     two single-image configurations of supplementary Fig. S3)
  SRIM 30 keV - Monolayer Long/  Semi-infinite SRIM ionization run (model input)
  SRIM-Thickness-Series/         Finite-thickness SRIM deposition profiles
scripts/
  extract_roi_intensity.py   ROI intensity extraction from the raw images
  prepare_roi_tables.py      Reconstruction/verification of the analysis tables
  bayesian_normalize.py      Bayesian carbon-reference normalization (PyMC)
  fit_se_models.py           SE-escape model definitions
  paper_model_comparison.py  Three-model comparison fit and the paper figure
  thickness_aware_fits.py    Refits with finite-thickness deposition profiles
  david_model_exploration.py Model-exploration history (identifiability checks)
  tape_interception.py       Geometric converter-interception estimate
  ROI.py                     Polygon-ROI definition tool used for the tape series
  se_roi_measurement_optimized.py  Tape-series ROI intensity measurement
analysis/
  tape/              Copper-tape converter series: descriptive statistics and
                     Bayesian outputs for the no-tape/small/large configurations
  bayesian_outputs/  Bayesian normalization outputs (transmission, blocked,
                     cross-geometry) including posterior peak-position samples
  srim_campaign/     SRIM transmitted-ion campaign: control manifests, inputs,
                     and processed per-thickness metrics
sensitivity/
  src/, scripts/     Full-covariance (EIV) sensitivity campaign package
  outputs/           Production Bayesian posteriors and sensitivity fit results
docs/                Fit reports (thickness sweep, finite-thickness refits,
                     final model comparison, foil-literature comparison)
tests/               Numerical acceptance tests for the SE-escape models
outputs/             Model-comparison figure as generated by the scripts
```

## Reproducing the main results

Python >= 3.11 with the dependencies in `requirements.txt`
(NumPy, SciPy, pandas, Matplotlib; PyMC and ArviZ for the Bayesian steps).

- `python scripts/prepare_roi_tables.py --check-only` verifies that the
  analysis tables reconstruct exactly from the raw ROI exports.
- `python scripts/bayesian_normalize.py` regenerates the normalized-intensity
  posteriors (deterministic: fixed seed; sampler settings in the script).
- `python scripts/paper_model_comparison.py` runs the symmetric,
  free-escape-depth, and asymmetric model fits, prints every number quoted in
  the paper, and writes `outputs/paper_model_comparison.pdf`. The fits are
  deterministic and reproduce to every printed digit.
- `python scripts/tape_interception.py <campaign-root>` computes the
  converter-strip interception fractions from the SRIM transmitted-ion
  records (see below for the campaign archive).

`PROVENANCE.md` maps every repository file to its original acquisition
filename and documents the ROI-table reconstruction rules.

## Large-file note

The full SRIM transmitted-ion campaign archive (118 runs, 48 thicknesses,
~1.2 GB) exceeds ordinary repository limits and is not tracked here. The
processed per-thickness metrics derived from it are preserved under
`analysis/srim_campaign/`, together with the campaign control manifests and
input files needed to regenerate the archive with SRIM-2013. The raw archive
is available from the corresponding author on reasonable request.
